Task Management Web App
Overview

A full-stack productivity web application built using Flask and SQLite. The application allows users to create, manage, prioritize, and track tasks with due dates and completion status.

Features

Create tasks with priority and due date
Update task completion status
Delete tasks
Automatic sorting by due date
Responsive dashboard-style interface

Tech Stack
Python
Flask
SQLite
HTML / CSS
Jinja Templating

INSTALLATION
pip install -r requirements.txt
python app.py
